# תזכורת הזרקה — iPhone PWA

אפליקציה אישית בחינם, בעברית ובכיווניות RTL, להתקנה ממסך הבית ב־Safari. המאגר פרטי; האתר שייפרס ל־Cloudflare יהיה נגיש ברשת בכתובת שקיבלת, והנתונים האישיים קשורים למזהה אקראי שמאוחסן במכשיר.

## מה האפליקציה עושה

- תאריך ההזרקה הבא = תאריך ההזרקה המתוכנן הקודם + 14 ימים, **גם אם האישור בוצע באיחור**.
- 13 ימים אחרי ההזרקה: תזכורת בשעה 20:00 שההזרקה למחרת.
- ביום ההזרקה: 10:00, 14:00, 18:00 ו־22:00, עד לאישור ״הזרקתי״.
- אחרי שתי הזרקות בחבילה: תזכורת לרכישת חבילה ביום שלמחרת בשעה 10:00; אם זה שבת, ביום ראשון בשעה 10:00.
- כפתור ״רכשתי חבילה חדשה״, מונה של שתי זריקות, תאריך ההזרקה הקרובה והיסטוריה.
- בהגדרה הראשונה בוחרים האם נותרו 1 או 2 זריקות בחבילה.

היסטוריית ההזרקות נשמרת מקומית בדפדפן/אפליקציית מסך הבית. השרת שומר רק תאריך עוגן, אזור זמן, מועדים שאושרו, מועד רכישה מתוזמן וכתובת Push Subscription. אין שימוש בחשבון משתמש, מעקב פרסומי או שמות תרופות.

## פריסה בחינם ב־Cloudflare Workers

1. היכנס ל־https://dash.cloudflare.com/ (אפשר להירשם לתוכנית Free).
2. עבור אל **Workers & Pages** ואז **Create application** → **Import a repository / Get started**.
3. חבר GitHub ואשר ל־Cloudflare גישה למאגר הפרטי `OrFainguersch/injection-reminder-pwa`.
4. בחר את המאגר ואת ענף `main`.
5. חשוב: שם ה־Worker ב־Cloudflare צריך להיות **`injection-reminder`**, בהתאם לשדה `name` בקובץ `wrangler.jsonc`.
6. Build/Deploy command: **`npx wrangler deploy`**. Root directory: שורש המאגר. במקרה שהממשק מציג גם Build command וגם Deploy command, אפשר להשאיר את Build command ריק/ברירת מחדל ולרשום את פקודת הפריסה בשדה Deploy.
7. לחץ **Save and Deploy**. בסיום תתקבל כתובת מאובטחת `https://injection-reminder.<subdomain>.workers.dev` או כתובת ש־Cloudflare תבחר.

### התקנה באייפון

1. פתח את הכתובת שהתקבלה ב־Safari.
2. בחר **שיתוף → הוסף למסך הבית**.
3. פתח את האפליקציה **מהאייקון במסך הבית** (לא מתוך הלשונית ב־Safari).
4. הזן תאריך ההזרקה האחרון וכמה זריקות נותרו.
5. לחץ **אפשר התראות** והענק הרשאה.
6. מתוך **הגדרות** לחץ **בדיקת התראה** ובדוק שהגיעה התראת Push בפועל.

## דברים שחשוב לדעת

- ההתראות דורשות iOS 16.4 ומעלה, מסך בית, אישור הרשאות, חיבור אינטרנט ושירות Push זמין. ״הפרעה שקטה״ ו־Focus עשויים להשתיק אותן. **אין להסתמך על התזכורות כמקור יחיד לניהול טיפול רפואי**.
- אחרי אישור ״הזרקתי״, הודעות עתידיות של אותו מועד יבוטלו בצד השרת כאשר יש חיבור רשת. הודעות שכבר נשלחו לא נמחקות בדיעבד.
- אם האייפון אופליין בעת האישור, האירוע יסתנכרן בחזרה לרשת, אבל ייתכנו התראות שנשלחו עד אז.
- לא נדרש מנוי Apple Developer, App Store או שרת אישי. Free tier של Cloudflare כולל מגבלות שימוש; עבור שימוש פרטי קטן הן לרוב מספיקות.
- האפליקציה לא משנה מינון, תדירות טיפול או הנחיות מרופא; היא רק עוקבת אחרי התאריכים שבחרת.
- הקוד כולל GitHub Action של `npm install`, בדיקת JavaScript ובניית Wrangler Dry Run.

## מבנה הקבצים

- `public/index.html`, `public/styles.css`, `public/app.js` — הממשק
- `public/manifest.webmanifest`, `public/sw.js`, `public/icons/` — PWA והודעות
- `src/worker.js` — צד שרת, VAPID, תזמון Durable Objects
- `wrangler.jsonc` — הגדרות הפריסה
- `package.json` — תלות ב־Luxon ובספריית Web Push
