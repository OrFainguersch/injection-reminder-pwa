# תזכורת הזרקה — PWA לאייפון

אפליקציה אישית למחזור הזרקה קבוע של 14 ימים. הפרויקט כולל ממשק דפדפן להתקנה למסך הבית, התראות Web Push ותזמון ב־Cloudflare Workers.

## התקנה ופריסה

האפליקציה תופיע בכתובת HTTPS אחרי חיבור המאגר ל־Cloudflare Workers ופריסה. יש להוסיף את האתר למסך הבית באמצעות Safari כדי להפעיל התראות באייפון.

הקוד נועד לתזכורות בלבד ואינו תחליף להנחיות רפואיות.
